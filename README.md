# Kumar Construction — Luxury Real Estate & Infrastructure Advisory Portal

A clean, high-performance, ultra-luxury multi-page **React (React Router v6) + Tailwind CSS** application created for **Kumar Construction**.

---

## 🏛️ Dedicated Pages & Routes

1. **Home (`/`)**:
   - High-definition video hero with zoom crop (`BUILDING LEGACY`).
   - Architectural advisory pillars statement & normalized cards.
   - Core Verticals infinite marquee auto-scroller with hover-to-pause.
   - Flagship Project highlight banner (Nirvana Valley) with direct link to case study.

2. **About Us (`/about`)**:
   - Dedicated page with architectural hero banner.
   - "The Firm - Bridging Capital & Execution - Redefining Real Value".
   - Our Origins (Est. 2023, Bengaluru HQ) & The Vision.
   - Leadership profiles: **Mr. Abdulla Kunhi, CA** & **Mrs. Mariambi Abdulla**.

3. **Projects Portfolio (`/projects`)**:
   - Dedicated portfolio page with landmark development showcases.
   - Full cards for **Nirvana Valley** (200 Acres, Nilambur) and **Skygarden Villas** (62 Eco-luxury villas, Magadi Road).
   - "View Case Study" direct navigation links.

4. **Project Case Study Detail (`/projects/:id`)**:
   - Dedicated full case study page (e.g. `/projects/nirvana-valley` and `/projects/skygarden-villas`).
   - Interactive photo gallery with main preview & slide selector.
   - Detailed masterplan overview, key features checklist, client specifications, and direct project inquiry CTA.

5. **Our Services (`/services`)**:
   - Dedicated advisory & consultation pricing matrix page.
   - 5 Practice Areas with dynamic duration selector (**1 Month, 3 Months, 6 Months, 1 Year**).
   - "Select Service" buttons that pre-populate the contact page.

6. **Contact Us (`/contact`)**:
   - Dedicated inquiry desk page with pre-fillable URL parameter support (`?service=...&duration=...&project=...`).
   - Form with real-time feedback and Bangalore headquarters office details.

---

## 💻 How to Run

```bash
# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
